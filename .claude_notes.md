# Claude Development Notes

## Current Session (2025-10-04)

### Major Improvements - Navigation & Costmaps
1. **Costmap Configuration**
   - Configured local and global costmaps to use `/scan_merged` (all 3 LIDARs combined)
   - Fixed local costmap dynamic obstacle detection with proper update rates (5Hz update, 2Hz publish)
   - Extended LIDAR obstacle detection range to 8m (from 2.5m)
   - Extended raytrace clearing range to 8m for better obstacle clearing

2. **Robot Footprint**
   - Replaced circular `robot_radius: 0.45` with accurate rectangular footprint
   - Footprint: `[[0.55, 0.38], [0.55, -0.38], [-0.55, -0.38], [-0.55, 0.38]]` (1.1m x 0.76m)
   - Helps prevent false obstacle detection from robot's own body

3. **LIDAR Wheel Clipping Fix**
   - Reduced LIDAR angle range from 127° to 100° (±0.8727 radians)
   - Prevents LIDARs from detecting robot's own wheels during turns
   - Modified `description/lidar.xacro` for all 3 LIDARs (front, left, right)

4. **Obstacle Avoidance Tuning**
   - Reduced inflation radius from 0.75m to 0.50m for tighter navigation through narrow spaces
   - Allows robot to navigate closer to obstacles while maintaining safety

5. **SLAM Mapping System**
   - Created `launch/slam_launch.py` with SLAM Toolbox
   - Configured for 8m max range with merged LIDAR scans
   - Aggressive loop closure settings to fix drift/ghosting issues
   - Added lifecycle manager for auto-start
   - Created `arena_boulder_map` using SLAM with boulders

6. **Map Management**
   - All launch files now use `arena_map.yaml` as default
   - Removed `usc_arena` map files (consolidated to arena_map)
   - Fixed map origin alignment: Gazebo coordinates now match map coordinates
   - Map origin shifted by (+1, +1) so initial pose (1,1) aligns with Gazebo (1,1)

7. **Makefile Enhancements**
   - Added `make slam` - Launch SLAM mapping
   - Added `make save-map` - Save current SLAM map with custom name
   - Added `make load_map` - Load arena map for visualization
   - Added `make load_boulder_map` - Load arena boulder map
   - Updated `make full-nav` to use arena_boulder_map

8. **Visual Improvements**
   - Made waypoint markers nearly invisible in Gazebo
   - Reduced from 0.1m tall cylinders to 0.01m flat discs
   - Semi-transparent (alpha 0.3) with dimmer green color
   - Positioned at ground level (z=0.005m)
